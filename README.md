# Municipal IT Incident Ontology

Author: Omar García Carballo (cerredax). Version 1.1.

OWL 2 course project for a municipal IT helpdesk. Documentation generated with WIDOCO 1.4.26.

- `ontology.owl`: RDF/XML.
- `ontology.ttl`: Turtle.
- `index.html`: documentation for GitHub Pages.

Namespace prepared for registration: https://w3id.org/municipal-it-incidents#

Publication is not complete until GitHub Pages is live and the w3id request is merged.

Version 1.1 replaces the example namespace and enriches metadata and property comments; domain axioms remain unchanged from version 1.0.
